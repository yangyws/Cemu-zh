# **Cemu - Android 移植版 (Wii U 模擬器)**

這是以 C/C++ 編寫的 Wii U 模擬器 **Cemu** 的 Android 移植版。
目前仍處於早期且實驗性階段。穩定性、效能與功能均無法保證，且相較於桌面版本可能會缺少部分功能。

目前沒有關於此移植版何時完成或何時實作新功能的時間表。

**請暫時不要提出 Issue 或 Pull Request。**
開發工作仍在進行中，一旦專案更加穩定，將會歡迎社群貢獻。

關於 Cemu 的一般資訊，請參閱[官方網站](https://cemu.info)與[主儲存庫](https://github.com/cemu-project/Cemu)。
